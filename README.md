# SignageLab Player downloads

Installers for the SignageLab Player. Get them from **[signage-lab.com/downloads](https://signage-lab.com/downloads)**, which always shows the latest version with its installation guide.

| Player | Release tag | Files |
|---|---|---|
| Android (TV boxes, sticks, smart TVs, tablets) | `android-v<version>` | `.apk` |
| Windows 10/11 64-bit | `desktop-v<version>` | `.msi` |
| Linux (Ubuntu 22.04+ / Debian 12+, x64 and ARM64) | `desktop-v<version>` | `.deb` |

Every version stays available under [Releases](../../releases). Each file's SHA-256 is shown next to it.
